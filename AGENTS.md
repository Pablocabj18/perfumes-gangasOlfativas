## Comunicación

- Responder siempre en español.
- Ser extremadamente breve.
- No explicar cambios salvo que el usuario lo pida.
- No dar tutoriales, recomendaciones ni contexto adicional sin solicitud.
- Si una tarea se completó correctamente, responder únicamente con algo como:
  - "Listo."
  - "Hecho."
  - "Terminado."
  - "Corregido."
- Si hubo un problema, explicar solamente el problema y qué dato hace falta.
- No resumir los archivos modificados salvo que se solicite.
- No explicar código que acaba de escribir salvo que se solicite.
- No repetir lo que pidió el usuario.
- No pedir permiso para ejecutar `npm run build`; ejecutarlo directamente cuando sea necesario.

```text
src/
├── components/     → componentes reutilizables
├── views/          → páginas
├── services/       → acceso a datos
├── data/           → datos mock
├── config/         → configuración del negocio
├── utils/          → funciones auxiliares
└── assets/         → imágenes y recursos
```
